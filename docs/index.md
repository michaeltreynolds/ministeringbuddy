# Ministering Buddy

A Chrome extension that helps an elders quorum presidency plan ministering changes alongside
Leader and Clerk Resources (LCR). It is a personal tool, not an official application of
The Church of Jesus Christ of Latter-day Saints, and is not affiliated with or endorsed by the Church.
