# Ministering Buddy privacy policy

*Last updated November 5, 2026*

Ministering Buddy is a personal tool used by its author. It is not an official application of
The Church of Jesus Christ of Latter-day Saints.

## What it reads
The extension reads ministering information from Leader and Clerk Resources (LCR), only for the
signed-in user and only what that user is already authorized to see there.

## Where data is stored
Data the extension saves, such as ministering categories and snapshots of assignments, is stored in a
Google Cloud Firestore database in a Google Cloud project owned by the user. Access is limited to that
user's Google account.

## Google sign-in
The extension uses the Google account signed in to Chrome to get permission to read and write that
Firestore database. It requests no other access to the account.

## What it does not do
- It does not sell or share data with anyone.
- It does not use analytics, advertising or tracking.
- It does not send data anywhere except the user's own Firestore database.
