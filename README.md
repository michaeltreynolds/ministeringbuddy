# Ministering Buddy

A Chrome extension to make ministering changes easier for an elders quorum presidency.
It works alongside Leader and Clerk Resources (LCR) and is not affiliated with or endorsed by
The Church of Jesus Christ of Latter-day Saints.

Rebuilding from scratch. The June 2025 prototype is in the git history before this commit, and its
original requirements are in [docs/reference/original-prompt-2025.txt](docs/reference/original-prompt-2025.txt)
(the names in that file are made up).
